# SUPER OGA: Wahala for Eko

A retro platformer set on the streets of Lagos. Oga Tunde's motor knocked at Oshodi, his
cousin Ronke is getting married on the Island today, and he promised to bring the family
aso-ebi. Six stages stand between him and the Owambe - and halfway there, somebody takes
the cloth off him.

| | Stage | |
| --- | --- | --- |
| 1-1 | Oshodi Under Bridge | Iya Ronke sends him to the tailor |
| 1-2 | Balogun Market | Tailor Kunle hands over the aso-ebi |
| 1-3 | Third Mainland Bridge | a danfo at the far end turns out to be one chance |
| 1-4 | Ojuelegba at Night | robbed and dumped; Baba Risi knows where the cloth went |
| 1-5 | Makoko Waterside | canoes and boards, to take it back |
| 1-6 | Lagos Island Go-Slow | the last run to the party |

Everything except the photographs is generated by code in this repo: the sprites are drawn
in JavaScript, written out as SVG, and converted to JPG; the music and sound effects are
synthesised live with WebAudio. No sprite editor, no audio files.

## Play

```sh
npm install
npm start          # then open http://localhost:5055
```

A plain `index.html` in a browser works too, as long as `npm run build` has been run at
least once (that writes `assets/bundle.js`, which inlines the JPGs so the game also runs
from `file://`).

### Controls

| | |
| --- | --- |
| **← →** | waka (walk) |
| **Z** / **Space** | jump |
| **X** | run (held); tapped it punches, or throws a pure-water sachet |
| **Enter** | talk to somebody: buy, haggle, hire a ride, climb aboard |
| **↑** | jump (and climb scaffolding) |
| **↓** | crouch, or comot from a ride |
| **Esc** / **P** | pause · **M** gbedu on-off · **C** credits |
| **I** | cheat mode on-off - nothing can kill Oga |

Enter talks to whoever is in front of you - buying, haggling, hiring a ride, climbing
aboard - and it sits beside the arrow keys, so the game is still playable with one hand.
Conversations are driven with up and down to pick an option and right to confirm.

Touch controls and gamepads work as well; the ENTER / COMOT buttons appear only when
there is something to enter or comot from.

`?stage=2-2` (or `?stage=5`) drops you straight into a stage, with the money, form and
aso-ebi you would plausibly have arrived carrying - useful for looking at one part without
replaying everything before it. The HUD says JUMPED IN so it is never mistaken for a real
run, and with no parameter the game starts normally at the title.

You start with five lives. Opening the game as `http://localhost:5055/?cheat` begins in
cheat mode, where a hit, a gutter, the lagoon and the clock all leave Oga standing - he is
simply put back on the last solid ground he stood on. **I** toggles it at any point, and
the HUD says CHEAT while it is on, so an ordinary game is never quietly altered.

## How it plays

The HUD shows ASO-EBI while Tunde is carrying the cloth. Losing it is the middle of the
story, not a game-over - but you do not reach the wedding without it.

Coins are naira, and naira is for spending. Mallam Sule sells suya that makes you Big Oga,
Mama Nkechi's puff-puff is an extra life, Iya Sikirat's pure water arms you with sachets,
and Nurse Bisi's clinic patches you up. Agberos stop you for union levy: settle them,
beg them, or refuse and face the consequences. Okadas and kekes are parked along the road
with their owners beside them, and the owners will haggle.

An okada is fast and fragile - one knock and you are on the floor. A keke is slower but
takes three. Both flatten most street wahala on contact.

Each stage has its own ambience under the music - traffic on the street, a crowd murmuring
across Balogun, water and wind on the bridge - and traders hawk at you as you come near.
The words are in the floating text, and the traders really say them - the lines are
recorded by [YarnGPT](https://yarngpt.ai), which does Nigerian voices, so Mallam Sule is
northern, Iya Sikirat is Yoruba, Mama Nkechi is Igbo. Where a recording is missing the game
falls back to a synthesised cry: a buzzy tone pushed through vowel formants, which reads as
somebody calling without ever being intelligible.

Mario's furniture is all here, wearing Lagos clothes: a foam mattress for a springboard,
scaffolding to climb instead of vines, a manhole that drops you into an under-bridge coin
stash and back, a flattened gutter rat that kicks like a shell, a shortcut that skips a
whole stage, swimmable lagoon in Makoko, and Fashe waiting at the end of it as a boss who
is a real fight: twelve hits, a life bar, leaps that shake the deck, and ten things he
says while he does it. The stage exit stays shut until he is down. A hundred coins is still a life, and
reaching a stage's end high still pays a bigger bonus.

And every so often NEPA takes the light. The music ducks away, crickets and mosquitoes take
over, and the street goes black except for a small pool around Oga and whatever is running
on a generator - until somebody shouts UP NEPA.

## Layout

```
index.html              the page: one 400x224 canvas, scaled up with hard pixel edges
src/
  core.js               constants, asset loading, the JPG colour-key decoder, pixel text
  input.js              keyboard, touch and gamepad, mapped to game actions
  music.js              the songs: Afrobeat / Afrobeats patterns as data
  audio.js              WebAudio: the kit, the sequencer, engines, sound effects
  levels.js             the three stages, written as ASCII chunks
  story.js              the cast, the prologue, and every conversation
  world.js              tile map, collisions, block bumps, spawning, drawing
  entities.js           Oga Tunde, his rides, the people, the wahala, pick-ups
  game.js               game states, story screens, HUD, main loop
  pixelfont.js          5x7 and 3x5 pixel fonts, used in game and baked into signage
tools/
  art/                  the sprites, drawn in code
  build-sprites.mjs     art -> assets/svg/*.svg -> assets/sprites/*.jpg + manifest
  fetch-photos.mjs      downloads and processes the Pexels photos, writes CREDITS.md
  bundle-assets.mjs     inlines the JPGs so index.html runs from file://
  preview-music.mjs     renders a song to WAV so the groove can be auditioned
  preview-sound.mjs     renders an effect, a hawker's call or ambience to WAV
  offline-audio.mjs     the offline stand-in for WebAudio both previews run on
  check-levels.mjs      validates level geometry, reachability and references
  smoke-test.mjs        plays the whole game headlessly with scripted input
  capture.mjs           renders real frames to PNG, headlessly, for checking the art
  measure-jump.mjs      measures the real jump arcs, which check-levels.mjs relies on
  check-reach.mjs       proves every platform can be landed on AND stood on, by simulation
  check-mechanics.mjs   exercises each mechanic directly: spring, warp, shell, climb, swim, boss
  build-voices.mjs      records the spoken lines (YarnGPT Nigerian voices, or macOS say)
  serve.mjs             the little static server behind `npm start`
```

## Working on it

```sh
npm run build              # sprites + photos + bundle
npm run sprites            # just the sprite pipeline
npm test                   # level checks + a full headless playthrough
npm run shots              # render real frames to shots/ (add --scale=4 for bigger)
node tools/smoke-test.mjs --verbose   # a trace of that playthrough
node tools/measure-jump.mjs           # jump heights; re-run after touching the physics

node tools/preview-music.mjs eko 8 eko.wav   # audition a song
node tools/preview-sound.mjs list            # every effect, voice and ambience
node tools/preview-sound.mjs night 12        # 12s of blackout insects
ONLY_VOICE=shaker NO_NORM=1 node tools/preview-music.mjs eko   # isolate one kit voice
```

### Recording the voices

```sh
node tools/build-voices.mjs                 # record whatever changed
node tools/build-voices.mjs --sample "..."  # hear all 16 voices say one line, to cast it
node tools/build-voices.mjs --provider=say  # macOS voices instead, no API key needed
```

YarnGPT needs an API key in `YARNGPT_API_KEY`, read from the environment or from a local
`.env` file. **`.env` is gitignored and no key is ever written into the repo or the clips.**
Clips are cached by a hash of provider, voice and line, so re-running costs nothing until a
line actually changes. The cast is the `CAST` table at the top of the tool - change a voice
there and re-run to recast a character.

### Jump height and reachable platforms

Oga clears about **5.2 tiles** from standing and **6.2 tiles** at a run. `check-levels.mjs`
uses those numbers to prove every plank and ledge can actually be reached from somewhere
below - an unreachable platform looks like a step and is really a tease. If you change the
jump in `src/entities.js`, re-run `tools/measure-jump.mjs` and update the constants at the
top of `check-levels.mjs`.

### How the sprites work

`tools/build-sprites.mjs` packs every frame into an atlas, writes it as SVG, and rasterises
it to JPG. JPG has no alpha, so transparent pixels are painted magenta and each art pixel
becomes an 8x8 block - which lines up exactly with JPEG's 8x8 DCT blocks, so compression
cannot smear colour across pixel edges. At runtime the game samples the centre of each
block and treats magenta as transparent. The build decodes its own output and fails if that
round trip loses a colour.
